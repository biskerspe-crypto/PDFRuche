# Contributing to PDFRuche (AGPL-3.0)

Thank you for contributing! By contributing you agree that your contributions will be licensed under the same license as the project: **GNU AGPL v3 or later (AGPL-3.0-or-later)**.

## Requirements

* All new files should include a SPDX header:
```ts
// PDFRuche — based on PDFCraft
// Copyright (C) 2025 PDFRuche Team, Copyright (c) PDFCraft Team
// SPDX-License-Identifier: AGPL-3.0-or-later
```
* Do not add code under incompatible licenses (MIT, Apache without AGPL compatibility check).
* Keep `LICENSE` verbatim. Add modifications to `PDFRUCHE_MODIFICATIONS.md`.
* For network deployments, preserve the "Source" link in the footer/header (AGPL §13).

## DCO

By submitting a pull request you certify the Developer Certificate of Origin (DCO) and that you have the right to submit the work under AGPL-3.0-or-later.

## Questions

Open an issue or contact via `/contact`.
